Welcome

This system lets students and teachers request an empty classroom or the auditorium for 2-3 hours. Once you submit a request, it goes to the admin for approval. When approved, the room is officially allotted to you.

Login

How it works

  1. Student or teacher fills the booking request form.
  2. Request is sent to the admin with room, date, and time details.
  3. Admin checks if the room is free and approves or rejects it.
  4. If approved, the room is allotted to the requester.
