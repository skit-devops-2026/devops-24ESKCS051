What is this?

The Campus Room Booking System is a simple web app that lets students and teachers request an empty classroom or auditorium for 2-3 hours. Once a request is submitted, it goes to the admin for approval, and the room is officially allotted once approved.

Why it exists

Booking a room on campus usually means chasing down whoever holds the keys or asking around to see if a room is free. This project puts that whole process in one place: browse rooms, submit a request, and track its status, all from the same site.

Current phase

This is Phase 2 of the project. Booking requests and admin approvals are stored and managed in the browser using localStorage, so the flow works end-to-end without a backend server yet. A real backend and login system are planned for a later phase.
